# mfp

`mfp` is the universal executable for all `mfp-XXX` tools.

You can put it somewhere into your path, create symbolic links
and you have a whole set of `mfp-XXX` commands in a single executable:

    ln -s mfp mfp-cups
    ln -s mfp mfp-discover
    ln -s mfp mfp-ipp-usb
    ln -s mfp mfp-model
    ln -s mfp mfp-ppd
    ln -s mfp mfp-proxy
    ln -s mfp mfp-usb
    ln -s mfp mfp-virtual

It saves a lot of installation space, providing the same functionality.
